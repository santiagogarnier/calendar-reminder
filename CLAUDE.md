# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## What this project is

A Chrome extension ("Calendar AI Reminder") that watches the user's Google Calendar, detects events within the next 7 or 14 days, and sends a personalized preparation email via a Node.js backend. The email body is generated by Claude AI and may include a YouTube video recommendation when the event requires study or preparation.

## Two separate components

### Chrome Extension (root directory)
Plain JS files loaded directly by Chrome — no bundler, no build step.

| File | Role |
|---|---|
| `manifest.json` | MV3 config; declares OAuth2 scopes (calendar.readonly, gmail.send, userinfo.email) |
| `background.js` | Service worker; sets a daily `chrome.alarms` alarm and calls `revisarCalendario()` |
| `utils.js` | Shared helpers imported via `importScripts` in the service worker and via `<script>` in the popup: `obtenerEventos`, `enviarAlBackend`, `fueNotificado`, `marcarNotificado` |
| `popup.js` | Handles the "Conectar con Google" button; calls `chrome.identity.getAuthToken({interactive:true})` |
| `popup.html` / `popup.css` | Extension popup UI |

To load the extension: open `chrome://extensions`, enable Developer mode, click "Load unpacked", select the repo root.

### Backend (./backend)
Express server deployed on Railway at `https://calendar-reminder-production.up.railway.app`.

```
cd backend
npm install
node index.js          # starts on PORT env var or 3000
```

Required `.env` variables:
```
GMAIL_CLIENT_ID=
GMAIL_CLIENT_SECRET=
GMAIL_REFRESH_TOKEN=
ANTHROPIC_API_KEY=
YOUTUBE_API_KEY=
PORT=
```

## Key flows

**Daily check (`background.js → revisarCalendario`)**
1. Get OAuth token silently (`interactive: false`).
2. Fetch calendar events for the next 14 days via `obtenerEventos` in `utils.js`.
3. For each event: if 11–14 days away → mark as "14-day notification"; if 4–7 days away → mark as "7-day notification".
4. Skip if already notified (key `${eventoId}_${dias}` in `chrome.storage.local.eventosNotificados`).
5. POST to `/enviar-recordatorio` on the backend, then persist the notified key.

**Backend `/enviar-recordatorio` (`backend/index.js`)**
1. Ask Claude (`claude-sonnet-4-5`) to write the email body.
2. Ask Claude whether the event requires preparation (`requierePreparacion`).
3. If yes, search YouTube Data API v3 and append the top result to the email.
4. Send via Gmail API using a service-account OAuth2 client configured with a refresh token.

## Auth model

- **Extension → Google APIs**: uses `chrome.identity.getAuthToken` (the extension's own OAuth2 client declared in `manifest.json`). Token is stored in `chrome.storage.local`.
- **Backend → Gmail**: uses a separate Google Cloud OAuth2 client (`GMAIL_CLIENT_ID/SECRET/REFRESH_TOKEN`) through `googleapis` — completely independent of the extension's credentials.

## Anti-duplicate system

Notification deduplication lives in `chrome.storage.local` under the key `eventosNotificados` (an array of strings like `"eventId_7"` or `"eventId_14"`). This is checked and written in `utils.js:fueNotificado` / `marcarNotificado`.
